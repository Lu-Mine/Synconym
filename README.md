# 近意词 Synconym

> 各自想一个词，同时揭晓，从上一轮的词继续靠近，直到想到一起。

一个 2–4 人实时联机的小游戏，适合和朋友一边聊天一边玩。不用注册、不用下载：打开页面，建个房间，把房号或邀请链接发出去就能开局。

## 怎么玩

1. **建房间或加入** —— 房主在首页点「创建房间」，其他人输入 5 位房号，或直接打开邀请链接进来。
2. **各自准备** —— 准备好后点「准备」，非房主全员准备后，房主就能点「开始」。
3. **各写一个词** —— 同一轮所有人同时写，谁都看不到别人的词；倒计时结束前输入框里的内容就是答案。
4. **同时揭晓** —— 大家写出同一个词，直接算相遇；否则进入 5 秒投票，全票「是」也算相遇。
5. **再靠近一点** —— 没相遇就进入准备，下一轮继续写：看到上一轮的词，往彼此的方向再想一个。
6. **结束这局** —— 相遇即成功；一直没相遇会打满轮次上限，同样进入结算。

一轮大概几十秒，一局通常几分钟。

## 相遇之后

结算页会把整个过程摊开给你看：收敛曲线（可以导出 SVG）、每一轮每个人写的词、每轮的投票记录。从进入结算开始有 **30 秒**选择下一步：

| 选择 | 结果 |
|---|---|
| **重赛** | 全员都选重赛且至少 2 人，按当前设置直接开下一局 |
| **回房间** | 回到等待大厅，可以重新调设置再开 |
| **回主页** | 只有你自己离开，不打扰别人 |

有人在 30 秒内没选、或者一直没连回来，会被移出这间房。

## 房间设置

房主在创建时或等待大厅里都能改，开局后锁定：

| 设置 | 可选项 | 默认 |
|---|---|---|
| 轮次上限 | 4–20 轮 | 12 |
| 写词时限 | 15 / 30 / 45 / 60 秒 | 45 秒 |
| 准备时限 | 15 / 30 / 45 / 60 秒 | 30 秒 |
| 禁止重复词 | 开 / 关 | 开 |

投票时间固定 5 秒，不提供开关。

## 主题模式

想让联想更集中，就把模式调成「主题」。每局开始时随机抽一个主题并锁定整局——重赛会重新抽，可能又抽到刚才那个。

主题只是大家联想的共同范围，**不设禁词，也不自动判断你的答案算不算切题**，靠彼此默契。可选主题有 20 个：王者荣耀、B站UP主、欧美音乐、国语音乐、春节、火锅、高铁出行、校园、故宫、熊猫、海洋、天气预报、短视频、网购、手机、装修、露营、咖啡、传统中医、宠物。

## 写词的小规矩

- 每次 1–12 个字，只能是汉字、字母和数字；空格可以打，比较时会忽略。
- 比较前会统一繁简、大小写、全角半角和空格：`iOS 手机` 和 `ios手机` 算同一个词，`臺灣` 和 `台湾` 也算。
- 开启「禁止重复词」时，本局出现过的词不能再写（包括自己用过的）；写重了会被拦下，不会浪费这一轮，改一下再交。
- 打出标点或 emoji 打不进去；超长的内容会自动截断。

## 玩到一半

- **刷新、关标签页、网络断了**：席位和已交的词会留 90 秒，期间回来还是原来的位置，游戏不等人。
- **有人掉线时**：准备阶段会多等 10 秒，免得他刚回来就错过下一轮。
- **主动退出**：点退出就立刻离开，席位不会保留；想再玩可以重新加入等待中的房间。
- **只剩一个人**：本局直接中断，纪录不会保存，可以回房间重新等人。
- **房间没人动**：连续 5 分钟没有操作，房间自动关闭。

如果轮次上限设到 8 轮以上，每满 5 轮会停下来问一次：「继续下一轮，还是玩崩了？」。选「玩崩了」的人达到半数，本局就结束并且不保存记录；达不到半数就继续往下写。

## 你的名字

第一次进来会随机分到一个「形容词的水果」，比如「迷人的橙子」「狡猾的蘑菇」。随时点名字旁的改名按钮换一个，改了之后还是同一个你，对局记录不会断。

## 想自己架一个

游戏是一个单进程的 Node 应用，静态页面和 WebSocket 同端口，没有外部服务依赖：

```bash
npm install
npm start        # 默认 http://localhost:3000
```

- 需要 **Node 20 或更新**。`better-sqlite3` 固定使用 `^12`，请不要升到 13.x——它要求 Node 22+，在 Node 20 上会直接崩溃。
- 对局记录存在 `data/synconym.db`（SQLite），部署时把这个目录挂到持久卷即可。
- 环境变量：`PORT`（默认 3000）、`PUBLIC_URL`（生成邀请链接用的对外地址）、`DB_PATH`（数据库路径）。
- 反向代理需要把 `/ws` 的 Upgrade 头转发过来。
- 开发时用 `npm run dev`（改动自动重启），此时还能打开 `/__mock` 预览各阶段界面；`npm start` 不开放这个入口。

完整的玩法细节、协议与设计规范见 [DESIGN.md](DESIGN.md)。
